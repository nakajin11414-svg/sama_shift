# スタッフの使い方

## 1. ログイン

LINEグループに送られたURLを開き、「LINEでログイン」を押します。初回は「管理者の登録待ちです」と表示されます。管理者があなたを名簿に登録すると使えるようになるので、少し待ってください。

## 2. 希望を入れる（希望入力タブ）

1. 画面上部の「‹ ○年○月 ›」で入力したい月を表示する
2. 入れる日付をタップして選ぶ。複数選べます。「全選択」「平日のみ」「土日祝のみ」でまとめて選ぶこともできます
3. 下の枠で時間を選ぶ
   - ランチ／ディナー／通し はボタンを押すだけ
   - 途中の時間だけ入れる場合は、開始・終了の時刻を入れて「時間指定で登録」
4. 選んだ日全部に同じ時間が登録されます。日によって違う時間にしたいときは、日付を選び直して繰り返してください
5. 間違えたら、日付を選んで「選択日の希望を取り消す」

## 3. カレンダーの印

| 表示 | 意味 |
| --- | --- |
| L / D / 通 / 10-14 | あなたが入れた希望（時間指定は開始〜終了の時） |
| ✓ | 管理者が承認した。この日は出勤です |
| ✕ | 今回は入れませんでした（人数が揃ったなど） |
| 印なし | 管理者の確認待ち |
| 募集中（赤字） | 人が足りない日。入れるなら希望を出してください |

承認された日を後から書き換えると、確認待ちに戻ります。急な変更は管理者に直接伝えてください。

## 4. 確定シフトを見る（確定シフトタブ）

管理者が公開すると、その月のシフト表が表示されます。公開前は「まだ公開されていません」と出ます。

- 自分の名前をタップすると、出勤日と時間の一覧が右に出ます
- 日付をタップすると、その日に誰が入っているかが出ます
- 表は名前を固定したまま横にスクロールできます
