# スタッフの使い方

## 1. ログイン

LINEグループに送られたURLを開き、「LINEでログイン」を押します。初回は「管理者の登録待ちです」と表示されます。管理者があなたを名簿に登録すると使えるようになるので、少し待ってください。

## 2. 希望を入れる（希望入力タブ）

1. 画面上部の「‹ ○年○月 ›」で入力したい月を表示する
2. 入れる日付をタップして選ぶ。複数選べます。「全選択」「平日のみ」「土日祝のみ」でまとめて選ぶこともできます。灰色の「定休日」はお店が休みの日なので選べません
3. 下の枠で入れる枠を選ぶ
   - 仕込み／ランチ／ディナー を1つ以上タップして「この枠で登録」（「通し」はランチからディナーまで。仕込みと組み合わせることもできます）
   - 途中の時間だけ入れる場合は、開始・終了の時刻（8〜22時）を選んで「時間指定で登録」。終了は「ランチ終業」「ディナー終業」も選べます
4. 選んだ日全部に同じ時間が登録されます。日によって違う時間にしたいときは、日付を選び直して繰り返してください
5. 間違えたら、日付を選んで「選択日の希望を取り消す」

### 運営・社員の人

運営・社員は、休みたい日だけを入れます。日付を選んで「休み希望で登録」を押してください（カレンダーに「休」と出ます）。それ以外の日は出勤予定で、何時にどの枠に入るかは管理者が決めます。決まった日はカレンダーに枠と ✓ が出ます。

### 締切と変更依頼

カレンダーの上に「締切: ○/○ まで」と出ている月は、その日の終わりまでに希望を入れてください。締切を過ぎると、「募集中」の日以外は直接変更できなくなります。

締切後に変えたいときは、変更依頼を送ります。

1. 変えたい日付をタップして選ぶ（下の枠が黄色の「変更依頼」に変わります）
2. 理由を書く（例: 学校の予定が入ったため）
3. 追加・変更なら枠を選んで「この枠で変更依頼」または「時間指定で変更依頼」、休みたいなら「選択日の取り消しを依頼」
4. 管理者が承諾すると希望に反映されます。送った依頼と結果（確認待ち・承諾・却下）は画面の一番下に出ます。確認待ちの間は「取り下げ」もできます

「募集中」の日と、それ以外の日を一緒に選ぶことはできません。分けて選んでください。

## 3. カレンダーの印

| 表示 | 意味 |
| --- | --- |
| 仕 / ラ / デ / 通 / 仕ラ / 10-14 | あなたが入れた希望（仕＝仕込み、ラ＝ランチ、デ＝ディナー、通＝通し。時間指定は開始〜終了の時） |
| 他店 | 別の店舗に出した希望がある日 |
| ✓ | 出勤。この日は入ってください |
| ✕ | 休み。今回は入れませんでした（人数が揃ったなど） |
| 印なし | 管理者の確認待ち |
| 募集 ラ1 デ2（赤字） | 人が足りない日。足りない枠とあと何人か（ラ＝ランチ、デ＝ディナー、仕＝仕込み）。入れるなら希望を出してください（締切後でも直接入れられます）。カレンダーの上にも「ランチあと1人」のように一覧で出て、タップで選べます |
| 依頼中 | 変更依頼を送って、管理者の確認を待っている日 |

出勤になった日を後から書き換えると、確認待ちに戻ります。締切後の変更は変更依頼から送ってください。

## 4. 確定シフトを見る（確定シフトタブ）

管理者が公開すると、その月のシフト表が表示されます。公開前は「まだ公開されていません」と出ます。

- 自分の名前をタップすると、出勤日と時間の一覧が右に出ます
- 日付をタップすると、その日に誰が入っているかが出ます
- 表は名前を固定したまま横にスクロールできます

## 5. 複数の店舗に入る人

画面上部の店舗プルダウンで店舗を切り替えてから希望を入れます。確定シフトの店舗の表の下に、自分の全店舗の出勤日がまとめて表示されます。

## 6. お知らせ

「お知らせ」タブに管理者からの連絡が届きます。未読があるとタブに件数が表示されます。
