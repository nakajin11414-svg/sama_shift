# 管理者マニュアル

## 1. このアプリでできること

スタッフが出せる希望を集め、管理者が日ごとに出勤・休みを決めて人数を揃え、確定したシフトを全員に公開するまでを1つのURLで行います。

毎月の流れ: スタッフが希望を入力 → 管理者が日ごとに出勤・休み → 足りない日は再募集 → 揃ったら公開 → 全員が確定シフトを見る。

| タブ | 誰が見える | 使う場面 |
| --- | --- | --- |
| 希望入力 | 全員 | スタッフは自分の希望を入れる。管理者は誰の希望でも代理で入力できる |
| お知らせ | 全員 | 管理者からのお知らせ。投稿は管理者のみ |
| 管理者 | 管理者のみ | 出勤・休みの決定・名簿・基準人数の管理と公開 |
| 確定シフト | 全員 | 公開後の完成シフト表。公開前は管理者だけプレビューできる |

画面上部の「‹ 2026年9月 ›」で月を切り替えます。表示・入力・出勤の決定・公開はすべて月単位です。

## 2. ログインと管理者の権限

ログインはLINEアカウントのみで、パスワードはありません。スマホのLINE内ブラウザから開くと、ほぼ自動でログインされます。

| 状態 | 意味 | できること |
| --- | --- | --- |
| 登録待ち | LINEでログインしたが、まだ名簿に載っていない | 何もできない。「管理者の登録待ちです」と表示される |
| スタッフ | 管理者が名簿に登録した | 自分の希望の入力、公開後の確定シフトの閲覧 |
| 管理者 | 最初にログインした人、または他の管理者が指名した人 | 上記すべてに加えて、出勤・休みの決定・名簿・基準人数・公開 |

管理者にしか見えない操作は、画面を隠しているだけでなく、データベース側でも他の人からの変更を弾いています。スタッフが自分の希望を書き換えると出勤・休みは自動的に「未定」に戻ります。

管理者は何人でも置けますが、最後の1人は「管理者を外す」ことができません。

## 3. スタッフ名簿（管理者 → スタッフ名簿）

名簿に載っている名前だけがシフト表に並びます。スタッフ本人は名前を入力できず、管理者が決めた名前がそのまま使われるので、表記のずれが起きません。

### 新しいスタッフを迎える手順

1. LINEグループにアプリのURLを送り、本人にログインしてもらう
2. 「スタッフ名簿」タブの上部に、黄色い枠で「LINEでログインした登録待ちの人」として表示される
3. 名前欄を確認する。初期値はLINEの表示名なので、シフト表で使う名前に書き換える
4. 「この名前で登録」を押す。その瞬間から本人の画面で希望が入力できる

名簿に名前だけ先に作っておくこともできます。その場合、本人がログインしたら登録待ちの行にある「既存の名前に紐づける…」から名前を選びます。

### 自分自身を名簿に載せる

管理者もシフトに入るなら、名前を「追加」してから、その行の「これは自分」を押します。押さないと「希望入力」で自分の名前が選べません。

### 絞り込みと並べ替え

名簿の上の欄で、名前の検索と、役職・所属店舗・できる仕事・LINE連携の有無による絞り込みができます。並べ替えは登録順・名前順・役職順（運営→社員→アルバイト）・店舗順から選べます。絞り込み・並べ替えは名簿の表示が変わるだけで、シフト表の並び順は変わりません。

### その他の操作

| ボタン | 動き |
| --- | --- |
| 名前の欄 | 直接書き換えると名前を変更（欄から離れるか Enter で保存）。過去の希望・実働もそのまま引き継がれる |
| 役職 | 運営・社員・アルバイトから選ぶ（初期値はアルバイト） |
| 管理者にする | そのスタッフに管理者の権限を与える |
| 管理者を外す | 管理者権限を戻してスタッフにする。管理者が1人だけのときは表示されない |
| 連携解除 | 名前とLINEアカウントの紐づけを外す。名簿の名前と過去の希望・実働は残り、名簿には「LINE未連携」と表示される。LINEアカウントは上の「登録待ち」に戻る。自分自身の行には表示されない |
| 名簿削除 | 「LINE未連携」の名前にだけ表示。名簿から消す。過去の希望・実働は残るが、シフト表には表示されなくなる |

### 退職したとき
1. 名簿でその人の「連携解除」を押す → LINEアカウントが「登録待ち」に移る
2. 登録待ちの一覧で「退職」を押す → このアプリのログイン情報が削除され、そのLINEアカウントではアプリを使えなくなる（本人のLINEアプリ側には何もしません）
3. 名前もシフト表から消したいときは、名簿で「名簿削除」を押す

登録待ちの「退職」は、関係ない人がログインしてきたときに一覧から消すのにも使えます。退職扱いにした人がもう一度LINEでログインすると、新しく登録待ちに表示されます（名簿に載せない限り何もできません）。

## 4. 基準人数と日の区分（管理者 → 基準人数）

各日は「平日」「土日祝」「イベント」のどれか1つの区分を持ち、区分ごとにランチとディナーの必要人数を決めます。

| 区分 | 初期値（ランチ／ディナー） | 自動で割り当てられる日 |
| --- | --- | --- |
| 平日 | 4人／4人 | 月〜金 |
| 土日祝 | 5人／5人 | 土・日と日本の祝日（振替休日・国民の休日を含め自動で判定） |
| イベント | 6人／6人 | なし（管理者が日ごとに指定） |

人数を変えるときは数字を書き換えて入力欄の外をタップすると保存されます。

### 特定の日だけ区分を変える

「シフト管理」で日付を選び、右側の「平日｜土日祝｜イベント」ボタンをタップします。通常と違う区分にした日は「（通常は平日）」のように注記が出ます。祝日は自動で「土日祝」になります。年末年始など祝日以外を土日祝扱いにしたい日は、その日を選んで「土日祝」に切り替えてください。

### 定休日

「店舗・基準人数」の「定休日（毎週）」で、毎週休みの曜日にチェックを入れます。臨時休業や、定休日だけど営業する日は、「シフト管理」で日付を選び、右側の「営業日｜定休日」で切り替えます（通常と違う日は「（通常は定休日）」のように注記が出ます）。

定休日はスタッフの希望入力で灰色の「定休日」と表示され、選べなくなります。シフト管理の日付リストでも灰色になり、募集ボタンは出ません。定休日にした日にすでに希望が入っている場合は、右側に「休業日ですが希望が○件あります」と出るので、「休み」にするなど対応してください。

### 人数の数え方

| 希望の種類 | ランチに数える | ディナーに数える |
| --- | --- | --- |
| ランチ | ○ | |
| ディナー | | ○ |
| 通し | ○ | ○ |
| 時間指定 | 11〜15時と重なれば○ | 17〜22時と重なれば○ |

休みにした希望は数に入りません。未定の希望は「+1」のように別枠で表示されます。

## 5. シフト管理（管理者 → シフト管理）

左に日付が縦に並び、右に選んだ日の希望者が並びます。左の人数表示が全部緑になるまで、右で出勤・休みを繰り返すのが基本の作業です。

### 左の日付リストの読み方

各日にランチとディナーの人数が「出勤/基準 +未定」の形で出ます。例: 「3/4 +2」は出勤3人、基準4人、未定2人。

| 色 | 意味 | 対応 |
| --- | --- | --- |
| 緑 | 出勤が基準とちょうど | 完了 |
| 黄 | 出勤が基準より少ない | 未定があれば出勤にする。なければ「募集」を押して再募集 |
| 赤 | 出勤が基準より多い | 誰かを「休み」にして減らす |

### 右の希望者リストの操作

| ボタン | 動き |
| --- | --- |
| 出勤／枠を変更 | 下に出勤の枠の選択欄が開く。最初は希望どおりの枠が選ばれているので、そのまま「この内容で出勤」で確定。人数に数えられ、公開後にシフト表に載る |
| 休み | 今回は入れないことにする。人数から外れ、本人の画面に「✕」が付く |
| 戻す | 出勤や休みを取り消して未定に戻す。枠を変えていた場合は元の希望に戻る |
| 未定をすべて出勤 | その日の未定をまとめて希望どおり出勤にする |

出勤の枠は、希望の範囲内でだけ選べます。

| 希望 | 選べる枠 |
| --- | --- |
| ランチ | ランチ、時間指定（ランチの時間内） |
| 通し | ランチ、ディナー、時間指定（ランチ開始〜ディナー終業の間） |
| 仕込み＋ランチ | 仕込み、ランチ、時間指定（仕込み開始〜ランチ終業の間） |
| 時間指定（例 10〜15時） | その時間に収まる枠（例: ランチ）、時間指定（10〜15時の間） |

枠は複数選べます。ランチとディナーを両方選ぶと「通し」、仕込みとランチなら「仕込み＋ランチ」として確定シフトに表示されます。時間指定は30分刻みです。希望と違う枠で出勤にした人には「（希望: 通し）」のように元の希望が小さく表示されます。本人の画面とシフト表には、管理者が決めた枠が表示されます。

休みは取り消せるので、まず多めに休みにしてあとから「戻す」、という進め方でも問題ありません。

### 再募集

人が足りない日は、左リストの「募集」を押して「募集中」にします。スタッフの入力画面でその日に「募集中」と赤く表示されます。足りたら再度押して解除します。締切後でも、募集中の日だけはスタッフが直接希望を入れられます。

### 運営・社員の出勤と事務日

運営・社員の出勤は、希望がなくても管理者が「シフト管理」で直接入れられます。

- 日付を選び、右側の一番下の「運営・社員の出勤を追加」で人を選ぶ → 仕込み・ランチ・ディナー・時間指定・事務から選んで「この内容で出勤」
- 希望を出している運営・社員の「出勤」でも、希望に関係なくすべての枠と事務を選べます（アルバイトは希望の範囲内だけ）

「事務」は運営・社員だけの出勤の種類です。出勤日（社員の休みの計算など）に数えますが、仕込み・ランチ・ディナーの人数には数えません。事務は「シフト管理」でだけ設定できます。


確定シフトでは「事」（一覧では「事務」）と表示され、日付をタップしたときの出勤者一覧にも「事務」として出ます。アルバイトには事務の選択肢は出ません。

### 社員の休み

「シフト管理」上部の「社員の休み」に、その月の社員の休みの日数を入れます（全店舗共通。入力欄から離れると保存）。役職が「社員」の人ごとに「○○：休み残り△日」と表示されます。

- 休み＝その月で出勤（承諾済み）がない日。どの店舗で出勤しても出勤に数えます。定休日も休みに数えます
- 休みが設定より多いときは、赤字で「休み残り0日（○日多い）」と出ます。出勤を増やしてください
- 右の小さい数字は出勤日数と、まだ未定の希望がある日数です

### 希望の締切

「シフト管理」上部の「希望の締切」で日付を選びます（店舗・月ごと）。その日の終わりまでスタッフは自由に希望を入れられ、締切を過ぎると「募集中」の日以外は直接変更できなくなります。「解除」で締切をなくせます。管理者は締切後も直接変更できます。

### 変更依頼（管理者 → 変更依頼）

締切後にスタッフが希望を変えたいときは、希望入力の画面から「変更依頼」が届きます。届くと「管理者」タブと「変更依頼」タブに件数が出ます。

一覧には、誰が・どの日を・今の希望 → 依頼内容（追加・変更の枠、または取り消し）・理由が表示されます。

| ボタン | 動き |
| --- | --- |
| 承諾 | 希望に反映する。追加・変更はそのまま「出勤」になり、取り消しはその日の希望を削除する |
| 却下 | 何も変えずに「却下」にする。スタッフの画面にも却下と表示される |

確認待ちの依頼は全店舗・全月分が表示されます。処理済みは表示中の月の分だけ表示されます。

## 6. スタッフの代理入力（希望入力タブ）

口頭やLINEで受けた希望、急な欠員の埋め合わせは、管理者が「希望入力」タブから直接入れられます。

1. 「希望入力」タブ上部の「編集する人」で相手を選ぶ（自分は「（自分）」付き）
2. 日付をタップして選ぶ。複数選択でき、「全選択」「平日のみ」「土日祝のみ」も使える
3. 「ランチ」「ディナー」「通し」を押す、または開始・終了の時刻を選んで「時間指定で登録」（終了は「ランチ終わりまで」「ディナー終わりまで」も選べます）
4. 取り消すときは日付を選んで「選択日の希望を取り消す」

管理者が入れた希望は、その場で「出勤」になります。本人が後からその日を書き換えると「未定」に戻るので、出勤画面で確認してください。

## 7. 公開と確定シフト

「シフト管理」上部の「○年○月分を公開する」を押すと、その月の出勤シフトが全員の「確定シフト」タブに表示されます。公開前に確認したいときは「確定シフト」タブの「管理者用プレビューを表示」を押します。

公開後も出勤・休み・代理入力は可能で、変更はすぐ確定シフトに反映されます。大きく組み直したいときは「公開を取り下げる」でいったん非公開にできます。

確定シフト表は縦に名前、横に日付。名前をタップするとその人の出勤日一覧、日付をタップするとその日の出勤者一覧が右側に出ます。

## 8. 毎月の運用チェックリスト

- 月初: 月を翌月に切り替え、イベント日などの区分を設定する（祝日は自動）
- 締切を決めてLINEグループで告知する
- 締切後: 「シフト管理」で全日を確認し、黄・赤の日をなくす
- 足りない日は「募集中」にしてグループで再募集する
- 全日が緑になったら「管理者用プレビュー」で表を確認する
- 「公開する」を押し、グループに公開したことを知らせる
- 公開後の変更は代理入力か出勤画面で行い、変更した人に伝える

## 9. 追加機能

### 複数店舗
画面上部の店舗プルダウンで表示する店舗を切り替えます。希望・出勤の決定・基準人数・公開はすべて店舗ごとです。店舗の追加・名前変更は「管理者 → 店舗・基準人数」、スタッフの所属店舗は「スタッフ名簿」の所属店舗チェックで設定します。複数店舗に所属する社員は、各店舗で希望を出せます。出勤画面では、同じ日に他店舗にも希望がある人に「他店も」と表示されます。

### 仕込み枠
ランチ・ディナーに「仕込み」が加わり、基準人数も3枠で設定します。希望は枠を複数選んで組み合わせられます（例: 仕込み＋ランチ、仕込み＋通し）。ランチとディナーの両方に入る場合は「通し」と表示します。時間指定の希望は「店舗・基準人数」で設定した各枠の時間帯と重なる枠に数えられます。

### デリバリー・厨房
「スタッフ名簿」の「できる仕事」でデリバリー・厨房・仕込みにチェックを付けます。「店舗・基準人数」で、平日・土日祝・イベントの区分ごとに「うち配達」「うち厨房」「うち仕込み」が何人必要かを設定します。配達・厨房の人数はランチとディナーに共通で、仕込みの人数は仕込みの枠だけに使います（初期値は各1人）。出勤画面では、出勤の人で足りない枠に「配達-1」「厨房-1」「仕込み-1」のように不足人数が出ます（日付リストでは「!」）。配達と厨房の両方ができる人は、どちらか一方にしか数えません。たとえば配達1人・厨房1人が必要な枠に、両方できる人が1人だけ入っている場合は「配達か厨房-1」と出ます。

### お知らせ
「お知らせ」タブから投稿できます。宛先は全店舗か特定の店舗を選べ、「上に固定」で常に先頭に表示できます。スタッフの画面では未読件数がタブに表示されます。

### 実働時間
「管理者 → 実働時間」で入力します。対象は役職が「アルバイト」の人だけです（運営・社員は表に出ず、確定シフトにも実働時間は表示されません）。

- 表の日付（またはその日のセル）をタップすると、その日の入力画面が開きます。時刻はすべてプルダウンで選びます（分単位）
- **終業**: 仕込み・ランチ・ディナーの終業を選びます。開始は「店舗・基準人数」の枠の時間帯で固定です
- **通しの休憩**: 休憩開始を選びます。休憩の終わりは17時固定です
- **デリバリー**: メインデリバリーと二台目デリバリーをした人を選びます。表に「配1」「配2」と出て、右端とCSVに月の回数が出ます
- **一人ずつ直す**: 下にその日働いた人が並びます。早上がり・遅刻は、その人の始業・終業を選び直すと「個別」になり、日の終業を変えても上書きされません。「個別 ✕」で元に戻せます
- 最後に「保存」。入力済みの日は日付に「入力済」、個別に直した人は数字に「*」が付きます

右端に月の合計時間が出て、「CSVを保存」で給与計算用に書き出せます。スタッフは確定シフトの自分の欄で実働時間を確認できます。

## 10. 困ったときのQ&A

| 症状 | 原因と対処 |
| --- | --- |
| スタッフがログインできない | LINE Developersのログインチャネルが「開発中」のまま。「公開済み」に切り替える |
| スタッフに「管理者の登録待ちです」と出る | まだ名簿に登録していない。第3章の手順で登録する |
| 管理者に同じ表示が出る | 自分を名簿に載せていない。名前を追加して「これは自分」を押す |
| 「管理者」タブが出ない | 管理者権限がない。他の管理者に「管理者にする」を押してもらう |
| 他の人の入力がすぐ反映されない | 画面を再読み込みする |
| 出勤にしたのに未定に戻っている | 本人がその日の希望を書き換えた。内容を確認してもう一度出勤にする |
| 画面が真っ白になる | 不具合。ブラウザでF12 → Consoleの赤い文字を控えて開発者に伝える |
| 公開したのにスタッフに表が見えない | スタッフ側で正しい月を表示しているか確認する |
