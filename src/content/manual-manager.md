# 管理者マニュアル

## 1. このアプリでできること

スタッフが出せる希望を集め、管理者が日ごとに承認して人数を揃え、確定したシフトを全員に公開するまでを1つのURLで行います。

毎月の流れ: スタッフが希望を入力 → 管理者が日ごとに承認・拒否 → 足りない日は再募集 → 揃ったら公開 → 全員が確定シフトを見る。

| タブ | 誰が見える | 使う場面 |
| --- | --- | --- |
| 希望入力 | 全員 | スタッフは自分の希望を入れる。管理者は誰の希望でも代理で入力できる |
| 管理者 | 管理者のみ | 承認・名簿・基準人数の管理と公開 |
| 確定シフト | 全員 | 公開後の完成シフト表。公開前は管理者だけプレビューできる |

画面上部の「‹ 2026年9月 ›」で月を切り替えます。表示・入力・承認・公開はすべて月単位です。

## 2. ログインと管理者の権限

ログインはLINEアカウントのみで、パスワードはありません。スマホのLINE内ブラウザから開くと、ほぼ自動でログインされます。

| 状態 | 意味 | できること |
| --- | --- | --- |
| 登録待ち | LINEでログインしたが、まだ名簿に載っていない | 何もできない。「管理者の登録待ちです」と表示される |
| スタッフ | 管理者が名簿に登録した | 自分の希望の入力、公開後の確定シフトの閲覧 |
| 管理者 | 最初にログインした人、または他の管理者が指名した人 | 上記すべてに加えて、承認・名簿・基準人数・公開 |

管理者にしか見えない操作は、画面を隠しているだけでなく、データベース側でも他の人からの変更を弾いています。スタッフが自分の希望を書き換えると承認状態は自動的に「未承認」に戻ります。

管理者は何人でも置けますが、最後の1人は「管理者を外す」ことができません。

## 3. スタッフ名簿（管理者 → スタッフ名簿）

名簿に載っている名前だけがシフト表に並びます。スタッフ本人は名前を入力できず、管理者が決めた名前がそのまま使われるので、表記のずれが起きません。

### 新しいスタッフを迎える手順

1. LINEグループにアプリのURLを送り、本人にログインしてもらう
2. 「スタッフ名簿」タブの上部に、黄色い枠で「LINEでログインした登録待ちの人」として表示される
3. 名前欄を確認する。初期値はLINEの表示名なので、シフト表で使う名前に書き換える
4. 「この名前で登録」を押す。その瞬間から本人の画面で希望が入力できる

名簿に名前だけ先に作っておくこともできます。その場合、本人がログインしたら登録待ちの行にある「既存の名前に紐づける…」から名前を選びます。

### 自分自身を名簿に載せる

管理者もシフトに入るなら、名前を「追加」してから、その行の「これは自分」を押します。押さないと「希望入力」で自分の名前が選べません。

### その他の操作

| ボタン | 動き |
| --- | --- |
| ↑ ↓ | シフト表での並び順を変える |
| 管理者にする | そのスタッフに管理者の権限を与える |
| 管理者を外す | 管理者権限を戻してスタッフにする。管理者が1人だけのときは表示されない |
| 外す | 名簿から消す。過去の希望データは残るが、シフト表には表示されなくなる |

## 4. 基準人数と日の区分（管理者 → 基準人数）

各日は「平日」「土日祝」「イベント」のどれか1つの区分を持ち、区分ごとにランチとディナーの必要人数を決めます。

| 区分 | 初期値（ランチ／ディナー） | 自動で割り当てられる日 |
| --- | --- | --- |
| 平日 | 4人／4人 | 月〜金 |
| 土日祝 | 5人／5人 | 土・日と、登録済みの祝日 |
| イベント | 6人／6人 | なし（管理者が日ごとに指定） |

人数を変えるときは数字を書き換えて入力欄の外をタップすると保存されます。

### 特定の日だけ区分を変える

「日程ごとの承認」で日付を選び、右側の「平日｜土日祝｜イベント」ボタンをタップします。通常と違う区分にした日は「（通常は平日）」のように注記が出ます。カレンダー上で赤くなっていない祝日があれば、その日を選んで「土日祝」に切り替えてください。

### 人数の数え方

| 希望の種類 | ランチに数える | ディナーに数える |
| --- | --- | --- |
| ランチ | ○ | |
| ディナー | | ○ |
| 通し | ○ | ○ |
| 時間指定 | 11〜15時と重なれば○ | 17〜22時と重なれば○ |

拒否した希望は数に入りません。未承認の希望は「+1」のように別枠で表示されます。

## 5. 日程ごとの承認（管理者 → 日程ごとの承認）

左に日付が縦に並び、右に選んだ日の希望者が並びます。左の人数表示が全部緑になるまで、右で承認・拒否を繰り返すのが基本の作業です。

### 左の日付リストの読み方

各日にランチとディナーの人数が「承認済み/基準 +未承認」の形で出ます。例: 「3/4 +2」は承認済み3人、基準4人、未承認2人。

| 色 | 意味 | 対応 |
| --- | --- | --- |
| 緑 | 承認済みが基準とちょうど | 完了 |
| 黄 | 承認済みが基準より少ない | 未承認があれば承認する。なければ「募集」を押して再募集 |
| 赤 | 承認済みが基準より多い | 誰かを「拒否」して減らす |

### 右の希望者リストの操作

| ボタン | 動き |
| --- | --- |
| 承認 | その人のその日を確定にする。人数に数えられ、公開後にシフト表に載る |
| 拒否 | 今回は入れないことにする。人数から外れ、本人の画面に「✕」が付く |
| 戻す | 承認や拒否を取り消して未承認に戻す |
| 未承認をすべて承認 | その日の未承認をまとめて承認する |

拒否は取り消せるので、まず多めに拒否してあとから「戻す」、という進め方でも問題ありません。

### 再募集

人が足りない日は、左リストの「募集」を押して「募集中」にします。スタッフの入力画面でその日に「募集中」と赤く表示されます。足りたら再度押して解除します。

## 6. スタッフの代理入力（希望入力タブ）

口頭やLINEで受けた希望、急な欠員の埋め合わせは、管理者が「希望入力」タブから直接入れられます。

1. 「希望入力」タブ上部の「編集する人」で相手を選ぶ（自分は「（自分）」付き）
2. 日付をタップして選ぶ。複数選択でき、「全選択」「平日のみ」「土日祝のみ」も使える
3. 「ランチ」「ディナー」「通し」を押す、または時刻を入れて「時間指定で登録」
4. 取り消すときは日付を選んで「選択日の希望を取り消す」

管理者が入れた希望は、その場で「承認」状態になります。本人が後からその日を書き換えると「未承認」に戻るので、承認画面で確認してください。

## 7. 公開と確定シフト

「日程ごとの承認」上部の「○年○月分を公開する」を押すと、その月の承認済みシフトが全員の「確定シフト」タブに表示されます。公開前に確認したいときは「確定シフト」タブの「管理者用プレビューを表示」を押します。

公開後も承認・拒否・代理入力は可能で、変更はすぐ確定シフトに反映されます。大きく組み直したいときは「公開を取り下げる」でいったん非公開にできます。

確定シフト表は縦に名前、横に日付。名前をタップするとその人の出勤日一覧、日付をタップするとその日の出勤者一覧が右側に出ます。

## 8. 毎月の運用チェックリスト

- 月初: 月を翌月に切り替え、祝日やイベント日の区分を設定する
- 締切を決めてLINEグループで告知する
- 締切後: 「日程ごとの承認」で全日を確認し、黄・赤の日をなくす
- 足りない日は「募集中」にしてグループで再募集する
- 全日が緑になったら「管理者用プレビュー」で表を確認する
- 「公開する」を押し、グループに公開したことを知らせる
- 公開後の変更は代理入力か承認画面で行い、変更した人に伝える

## 9. 困ったときのQ&A

| 症状 | 原因と対処 |
| --- | --- |
| スタッフがログインできない | LINE Developersのログインチャネルが「開発中」のまま。「公開済み」に切り替える |
| スタッフに「管理者の登録待ちです」と出る | まだ名簿に登録していない。第3章の手順で登録する |
| 管理者に同じ表示が出る | 自分を名簿に載せていない。名前を追加して「これは自分」を押す |
| 「管理者」タブが出ない | 管理者権限がない。他の管理者に「管理者にする」を押してもらう |
| 他の人の入力がすぐ反映されない | 画面を再読み込みする |
| 承認したのに未承認に戻っている | 本人がその日の希望を書き換えた。内容を確認して再承認する |
| 画面が真っ白になる | 不具合。ブラウザでF12 → Consoleの赤い文字を控えて開発者に伝える |
| 公開したのにスタッフに表が見えない | スタッフ側で正しい月を表示しているか確認する |
